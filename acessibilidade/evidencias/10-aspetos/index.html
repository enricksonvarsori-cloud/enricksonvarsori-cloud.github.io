RequisitoEstadoEvidência resumida
1.1 Menu estruturado como listaSimNavegação principal em <nav>, <ul>, <li> e ligações nativas.
1.2 Menu operável por rato e tecladoSimAs opções são ligações nativas focáveis e ativáveis por teclado; o foco é visível.
1.3 Imagens-link no menuNAO menu é exclusivamente textual.
2.1 Um título H1 por páginaSimAs sete páginas principais contêm exatamente um H1.
2.2 Hierarquia de títulosSimEstrutura consistente H1 → H2 → H3, sem saltos estruturais problemáticos na amostra.
3.1–3.2 Tabelas de dadosNANão existem tabelas de dados no sítio.
4.1–4.3 FormuláriosNANão existem formulários de introdução de dados.
5.1–5.3 Gráficos e imagens-linkNANão existem gráficos de dados nem imagens usadas isoladamente como ligações; os elementos visuais são decorativos.

6.2 Contraste de texto grandeSimAs páginas principais foram corrigidas e validadas sem ocorrências AA no AccessMonitor.
7.1–7.2 PlayersNANão existem elementos de áudio ou vídeo incorporados.
8.1 CSS removida: alinhamento linearSimO conteúdo segue o fluxo normal do HTML quando a apresentação visual é removida.
8.2 CSS removida: ordem lógicaSimOrdem DOM: skip link → header/nav → main → secções → footer.
8.3 Semântica reconhecívelSimUso de header, nav, main, section, article, footer, títulos, parágrafos e listas.
8.4 Informação permanece visívelSimO conteúdo essencial encontra-se em HTML textual; fundos e formas CSS são decorativos.
8.5 Layout sem tabelasSimO layout utiliza CSS Grid/Flexbox e elementos semânticos/genéricos, sem tabelas de apresentação.
9.1–9.4 ModaisNANão existem caixas de diálogo/modais.
10.1 PDFsNANão existem ficheiros PDF disponibilizados no sítio na versão analisada.
