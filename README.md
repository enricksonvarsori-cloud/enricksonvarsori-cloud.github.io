# Enrickson Varsori, PhD — Academic Website

Personal academic website of **Enrickson Varsori, PhD**, researcher in Communication Sciences working across digital media, human–computer interaction, sustainability and emerging technologies.

**Live site:** https://varsori.com/

## Website structure

- **Home** — research profile and selected work
- **About me** — research trajectory, academic background and affiliations
- **Research** — research areas, questions and methodological approach
- **Project Involvement** — selected collaborative research projects
- **Publications** — selected peer-reviewed publications
- **Impact** — research in practice, stakeholder engagement and uptake
- **Contact** — institutional email and academic/professional profiles

## Current research profile

The website presents an interdisciplinary research trajectory across:

- digital life, hyperconnectivity and temporalities;
- human–computer interaction, usability and UX;
- sustainability, environmental communication and stakeholder engagement;
- artificial intelligence and emerging technologies.

## Technical notes

The website is a static GitHub Pages site built with HTML, CSS and lightweight JavaScript. It includes:

- responsive layouts for desktop, tablet and mobile;
- accessible active-navigation states;
- custom EV favicon;
- Open Graph and social sharing metadata;
- Schema.org structured data;
- `sitemap.xml`;
- `robots.txt`;
- custom `404.html`.

## Version
